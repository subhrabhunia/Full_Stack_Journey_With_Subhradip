## 🛠️ How to View the Projects Locally

Follow these quick steps to explore the source code and run the pages in your browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_GITHUB_USERNAME/Full_Stack_Journey_With_Subhradip.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd Full_Stack_Journey_With_Subhradip
   ```

3. **Open any HTML file:**
   * Double-click any `.html` file inside the folders to launch it directly in your web browser.
   * *Alternative:* Open the root folder inside **VS Code** and use the **Live Server** extension for real-time changes.
