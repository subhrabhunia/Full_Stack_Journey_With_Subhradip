| ---------------------- | ------------------ |
| JavaScript             | PHP                |

2.Server Side Script: PHP, .NET, Python

Remember: JavaScript mainly runs on the client side, while PHP, Python, and ASP.NET run on the server side. HTML is a markup language, not a scripting language.
